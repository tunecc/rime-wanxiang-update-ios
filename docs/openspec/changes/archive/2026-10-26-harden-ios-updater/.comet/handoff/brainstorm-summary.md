## 已确认的技术方案

> 状态：2026-10-26 用户已确认。

1. 排除规则按模式是否含 `/` 区分：无 `/` 只匹配部署根目录，含 `/` 匹配完整相对路径；`custom/` 模板写入，根目录 `*.custom.yaml` 保留。
2. Release 选择改为标题（`万象拼音输入方案`、`词库`/`实时全量预览`）+ tag 正则；标题未命中时按 tag 回退并告警；移除 `sort -V`，改为逐段数值比较。
3. HTTP 使用 curl `-fSL --retry 3` / wget 重试；失败删除残包；应用前做大小 + sha256 校验；无哈希工具时告警降级，不判失败。
4. 方案新增 `custom/.scheme_sha256`：同版本哈希不同则更新、记录缺失则更新一次、本地更高不降级、全部一致则跳过。
5. 解析解压根：解压目录只有一个顶层目录时剥离；方案、词库共用，替代“压缩包名 = 顶层目录名”假设。
6. 词库先校验后解压覆盖；`dicts/` 缺失或为空强制更新。
7. 模型下载前比对本地文件哈希；下载到部署目录内临时文件，校验后 `mv` 原子替换。
8. 参数解析前移：`--help`/`--doctor` 不依赖 jq；带值参数检查缺值；`--depdir` 按路径含 `RimeUserData` 推断元书，否则仓。
9. CNB `page_size=100`、GitHub `per_page=100`，方案/词库共享 GitHub releases 缓存；移除 `TOOLS_API`。
10. 保持 bash 3.2/BSD 兼容，不新增依赖；方案更新成功后清理 `build/`；保留旧方案文件和用户数据。

## 关键取舍与风险

- 首次升级因哈希记录缺失会执行一次方案更新：有意行为，用于补齐模板与记录。
- CNB `page_size` 若被调整：回退默认分页并告警。
- 模型临时文件占用部署目录额外空间：失败时旧模型不受影响。
- 无哈希工具时仅大小校验：明确告警，建议安装 coreutils。
- 上游标题文案变化：tag 回退 + 告警。
